crocket tier layouts

A block is k warps (the ranks, each with its own instruction stream) holding P problems per warp. Each warp's 32 lanes split into P groups of 32 / P lanes; a group works on one problem's elements, and every lane runs the same shape-group statement. Pick a layout to see where each lane goes.

Presets
k: warps per block (ranks)
P: problems per warp
Powers of two, so 32 / P lanes divide evenly.
Items per shape group
How many elements of one problem share an expression shape in a warp's stage. traj_collision averages about 8.
